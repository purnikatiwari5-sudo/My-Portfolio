## 🚀 Projects

### 01 — AquaGuard

**Smart Water Level Monitoring & Safety System**

A first-semester IoT project designed to monitor water levels and provide warnings when the level becomes unsafe.

**Technologies & Components:**

- Arduino Uno
- Water-level sensor
- HC-05 Bluetooth module
- LEDs
- Buzzer
- Relay
- Water pump

The project combines hardware sensing, warning indicators and relay-based control to demonstrate a basic safety-monitoring system.
